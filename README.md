# Mini Sweet — GitHub Pages

This build is self-contained: all photography and the official logo are embedded directly in `index.html` / `styles.css`. No `assets/` folder or external image paths are needed.

## Publish
Replace the repository root files `index.html`, `styles.css`, `script.js`, and `README.md` with these versions. Keep GitHub Pages on `main` / `/(root)`.

## Final refinements
- Automatic hero slideshow cycling through at least four embedded bakery/pastry photos.
- One consistent official logo in the header and footer; duplicate hero badge removed.
- Decorative section and specialty-card numbering removed.
- Tighter mobile spacing and responsive two-column product cards, while retaining the desktop layout.
- French, Arabic RTL and English remain supported.
- Google Maps, Instagram, Facebook and phone links remain in place.

Menu images and prices remain illustrative placeholders until the client supplies approved photos and confirmed prices.
