# Mini Sweet — GitHub Pages website

This package contains the four files to place in the root of the existing GitHub Pages repository.

## Files
- `index.html` — complete website and all product photography embedded directly in the HTML.
- `styles.css` — responsive styling, animations and mobile layout.
- `script.js` — English-first language handling, Arabic RTL, navigation, menu filters and the automatic hero slideshow.
- `README.md` — these instructions.

## Publish the update
1. Open the existing `MiniSweet` GitHub repository.
2. Replace the existing `index.html`, `styles.css`, `script.js` and `README.md` with these files at the repository root.
3. Commit the changes and wait for GitHub Pages to publish.
4. Open the site and refresh once. If an older version is cached, use a private tab or clear the browser cache.

No assets folder or external image upload is required. All photos are embedded in `index.html` so they work with GitHub Pages.

## Included refinements
- English is the default for new visits; the visitor can still choose English, Arabic or French.
- Arabic uses right-to-left layout.
- The obsolete leaf logo and duplicate circular hero logo have been removed from the header and footer.
- The specialty cards use the earlier compact side-by-side image/text layout on mobile.
- The hero rotates through the embedded photos with smooth transitions.
- Decorative section and card numbering has been removed.
- Mobile and desktop layouts were checked at widths from 320px to 1440px.
