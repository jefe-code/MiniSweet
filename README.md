# Mini Sweet — GitHub Pages (Fixed)

Responsive, multilingual showcase website for Mini Sweet, Lastah, Taroudant.

## Publish on GitHub Pages
1. Download and extract `Mini-Sweet-GitHub-FIXED.zip`.
2. Upload **all extracted contents** to the root of your repository. Keep `index.html`, `styles.css`, `script.js`, `.nojekyll`, and the complete `assets/` folder together.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

Do not upload only `index.html`: the `assets/images/` folder contains every image and logo used by the page.

## Included
- French, Arabic (RTL), and English language selector.
- The client's original Mini Sweet logo, plus a matching extracted brand mark.
- Hero background and product photos bundled locally; no third-party image URLs are required.
- Three specialty cards that open their matching menu category: Boulangerie, Pâtisserie, or Viennoiserie.
- Responsive mobile and desktop layout, animated reveals, and reduced-motion support.
- Google Maps, Instagram, Facebook, and telephone links.

## Edit later
- Replace sample food photos in `assets/images/` with the client's own photos, keeping the same filenames.
- Add confirmed prices in `index.html` (the current `— MAD` values are intentionally placeholders).
- Edit translations and menu item names in `script.js`.
- Edit layout and colors in `styles.css`.
