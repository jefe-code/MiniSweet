# Mini Sweet — GitHub Pages (No assets folder required)

This build embeds all photos, the brand mark, and favicon directly into `index.html` and `styles.css` as Base64 data URLs. **There is no `assets/` folder and no image upload required.**

## Upload to GitHub
1. Open the `MiniSweet` repository.
2. Upload/replace these four files at the repository root: `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Do not create an `assets` folder. All visual assets are already embedded in the HTML and CSS.
4. Keep GitHub Pages set to branch `main`, folder `/(root)`.
5. Wait for deployment, then hard-refresh the page or open it in a private tab.

## Included
- French, Arabic RTL, and English.
- Embedded Mini Sweet brand mark and logo photo.
- Hero and all menu/gallery photos embedded locally (no external image hosting).
- Responsive layout, motion effects, menu category filters, map/social/telephone links.
- No build step, no dependencies, no server.

The food photos and menu prices are illustrative placeholders. Replace them with approved client photos and confirmed prices when available.
