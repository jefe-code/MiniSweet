# Mini Sweet — GitHub Pages (no assets folder)

All photos and the official Mini Sweet logo are embedded directly in `index.html` and `styles.css`. No `assets/` directory, external image hosting, build step or framework is required.

## Publish
1. Open the `MiniSweet` GitHub repository.
2. Replace the root files `index.html`, `styles.css`, `script.js`, and `README.md` with the files in this archive.
3. Do not upload an `assets/` folder.
4. Keep GitHub Pages set to branch `main`, folder `/(root)`.
5. Wait for deployment and open the site in a private tab or hard-refresh it.

## Included
- Official Mini Sweet logo reused in the header, hero, footer and browser tab icon.
- Embedded food photography, with no external asset paths.
- French, Arabic RTL and English.
- Responsive layout, navigation, menu category filters, Google Maps, Instagram, Facebook and telephone links.

Menu photos and prices are illustrative placeholders pending the client's approved photos and confirmed prices.
