# Mini Sweet — GitHub Pages Website

A responsive showcase website for Mini Sweet, a boulangerie, pâtisserie and viennoiserie in Lastah, Taroudant, Morocco.

## Publish on GitHub Pages

1. Download and extract `Mini-Sweet-GitHub-READY.zip`.
2. Upload **all extracted files and folders** to the root of the `MiniSweet` repository, replacing the previous files.
3. Keep the `assets/images/` folder in the same place as `index.html`.
4. Open **Settings → Pages** in GitHub. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub Pages to finish deploying, then refresh the website (clear the browser cache if an old version remains).

Do not upload only `index.html`. The image files are included locally in `assets/images/` and the website references them with relative paths, so GitHub Pages can serve them reliably.

## Included features

- French, Arabic (RTL) and English language selector.
- New full-width hero image with a dark cinematic overlay and subtle motion.
- Mini Sweet brand mark and the logo image sourced from the business's public Facebook page.
- All food images bundled locally; no external image-hosting links are required.
- Boulangerie, Pâtisserie and Viennoiserie specialty cards that open their matching menu category.
- Responsive mobile and desktop layouts, animated section reveals, and reduced-motion support.
- Clickable Google Maps, Instagram, Facebook and telephone links.
- Static HTML/CSS/JS: no paid service, build step, database or server required.

## Edit later

- Replace the sample food photos in `assets/images/` with the client's own photos, keeping the same filenames.
- Replace the `— MAD` placeholders with confirmed prices in `index.html`.
- Edit product names and translations in `script.js`.
- Edit layout, colors and animation in `styles.css`.
