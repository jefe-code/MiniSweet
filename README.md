# Mini Sweet — GitHub Pages

Static, responsive website for Mini Sweet (Lastah, Taroudant). No build tools or paid services are required.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload the contents of `Mini-Sweet-GitHub` to the root of your GitHub repository (keep `index.html`, `styles.css`, `script.js`, and `assets/` together).
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.

## Edit the site
- `index.html`: sections, links, images, phone number, address.
- `styles.css`: colours, layout, responsive rules and animations.
- `script.js`: French / Arabic / English text, language switch and menu filters.
- `assets/images/`: replace the sample images with Mini Sweet's real product photos, keeping the same filenames or updating the matching `src` paths.
